# Sprint_5
Автотесты для Stellar Burgers (https://stellarburgers.nomoreparties.site/)

Нужно проверить
1. Регистрация

1.1 Успешная регистрация:

-Поле «Имя» не должно быть пустым.

-Поле «Email» должно содержать email в формате логин@домен (например, 123@ya.ru).

-Пароль должен содержать минимум 6 символов.

1.2 Ошибка для некорректного пароля:

-Проверка отображения ошибки, если пароль меньше 6 символов.

2. Вход

2.1 Вход по кнопке «Войти в аккаунт» на главной странице.

2.2 Вход через кнопку «Личный кабинет».

2.3 Вход через кнопку в форме регистрации.

2.4 Вход через кнопку в форме восстановления пароля.

3. Переход в личный кабинет

Проверка перехода по клику на «Личный кабинет».

4. Личный кабинет

4.1 Переход из личного кабинета в конструктор

4.2 Проверка перехода по клику на «Конструктор».

4.3 Проверка перехода по клику на логотип Stellar Burgers.

4.4 Проверка выхода по кнопке «Выйти» в личном кабинете.

5. Раздел «Конструктор». Проверка переходов к разделам:

5.1 «Булки»

5.2 «Соусы»

5.3 «Начинки»
